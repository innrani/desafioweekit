# QR Code Quest

Jogo estático de perguntas de múltipla escolha sobre computação, com 5 níveis do mais fácil para o mais difícil.

## Como abrir

Abra diretamente qualquer página do desafio pelo navegador, por exemplo:

- atomo.html
- foton.html
- genoma.html
- quasar.html
- higgs.html

As fases são acessadas pela URL e não dependem de menu nem botão de avanço.
