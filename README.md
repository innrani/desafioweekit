# QR Code Quest

Jogo de caça ao QR Code com 5 fases de perguntas de múltipla escolha sobre computação, do nível mais fácil ao mais difícil.

## Como funciona

- A página inicial explica o desafio e os participantes devem encontrar os QR Codes espalhados pelo ambiente.
- Cada fase possui uma dica que indica onde o QR Code está localizado.
- O jogo funciona por URL: cada fase é acessada diretamente via link ou QR Code.
- Não há menu nem botão de próxima fase.
- Quando a resposta estiver correta, o participante recebe um ID único para registrar e mostrar depois.

## Estrutura

- index.html: página inicial com a explicação do jogo e as dicas dos 5 níveis
- atomo.html: nível 1
- foton.html: nível 2
- genoma.html: nível 3
- quasar.html: nível 4
- higgs.html: nível 5

## Como abrir

Abra a página inicial no navegador e siga as dicas dos níveis:

- index.html

Ou acesse diretamente qualquer fase pelo navegador:

- atomo.html
- foton.html
- genoma.html
- quasar.html
- higgs.html
